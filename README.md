A tiny chess engine in 4 KB of Python: 0x88 board, negamax alpha-beta with a transposition table and quiescence search, tapered piece-square evaluation, and iterative deepening on a fixed node budget (never a clock, so trials replay deterministically). It plays the house gauntlet through the env at MAKEFUN_ENV_URL.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
